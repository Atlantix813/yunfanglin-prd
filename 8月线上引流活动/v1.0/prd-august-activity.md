# 8月线上社区引流活动 · 商家活动页

## 需求背景

2026 年 7 月 22 日会议决定 8 月 15 日起开展纯线上社区引流活动，试点南医大、沙顶及金沙街相关社区，覆盖约 58 家商家。活动页是社区公告的单一承接入口，首期轻量，以统一页面承载不同社区内容。

## 需求说明

### 功能一 · 商家活动落地页

需求概述：为社区公告创建轻量级落地页。不同社区扫码进入后自动展示对应商家和券。支持一键领取全部活动券，新用户在页内完成注册。

###### 社区选择器 · 社区切换

1. 结构
   1. 左侧「当前社区：XX」，右侧「切换」入口和分享按钮。
   2. 位于主视觉卡片上方。
   3. 点击后底部滑出社区选择面板，包含搜索栏、最近使用标签、树形列表、确定/取消按钮。
2. 面板交互
   1. 搜索栏：输入关键字过滤社区列表。
   2. 最近使用：胶囊标签展示最近选择的社区，点击直接选中。
   3. 树形列表：父级节点带展开/收起箭头（›/⌄），子级节点点击选中，选中态蓝色高亮。
   4. 点击「确定」才生效切换，「取消」关闭面板不切换。
3. 联动
   1. 社区选择面板展示全区所有社区（来自组织树），不限制试点范围。
   2. 选择新社区后，页面券列表和商家列表按新社区展示。
   3. 选中没有参与活动的社区时，页面展示空状态。
   4. 注册弹窗中绑定社区名称同步更新。
   5. 企微群入口文案同步更新。

###### 主视觉区 · 活动卡片

1. 结构
   1. 活动名称、副标题。
   2. 活动时间范围胶囊标签。
   3. 右下角纯文字按钮「活动规则」。
2. 活动规则弹窗
   1. 点击「活动规则」底部滑出弹窗，展示活动规则详情。
   2. 规则内容覆盖：活动时间、参与商家、优惠券说明等，具体内容待运营确认。
3. 活动结束状态
   1. 活动时间外进入，隐藏整个限时活动券板块（券区标题、券列表、一键领取按钮）。
   2. 「活动已结束」按钮保留，置灰不可点击。
   3. 按钮下方展示引导：「前往领券中心查看更多优惠券 前往 ›」，点击跳转领券中心。
   4. Hero 卡片和各区域保持正常展示，不叠加半透明遮罩。

###### 活动券区 · 券列表 + 一键领取

1. 券卡片结构
   1. 多张券横向滚动排列（首屏露出 3 张）。
   2. 每张券仅展示面额和门槛描述，不设领取按钮。
   3. 已领取的券底部显示「已领取」标记。
2. 券取值规则
   1. 调两组接口：用户所选社区的券列表（按名称关键词如【福利节】过滤）、用户已领券列表。
   2. 券列表按所选社区筛选，切换社区后重新拉取。
   3. 剔除以下券，得到可展示券列表：
      1. 已下架的券。
      2. 库存为 0 的券。
      3. 非免费券（需要消耗积分兑换的券）。
      4. 仅新客券（适用人群=仅新客）但当前用户不符合新客条件（已在该券所属商家核销过优惠券）的券。
      5. 当前用户已领取张数达到每人限领上限的券。
   4. 判断规则：上述条件任一不满足，该券不展示在列表，也不参与一键领取。
   5. 已领券：可展示券列表中，用户已经领取过的那些（含已使用、未使用状态）。
   6. 可领券：可展示券列表中，用户还没领过的那些。
3. 按钮判定规则
   1. 可领券一张都没有（活动券全被领完了）→ 按钮置灰，文案「已领取」。
   2. 可领券哪怕只剩 1 张没领 → 按钮亮起，文案「一键领取」。
4. 券排序规则
   1. 可领券在前，已领券在后。
   2. 可领券内部纯随机排序。
   3. 说明：券种分为满减、折扣、兑换三类，面值含义不统一（减免金额 / 折扣力度 / 参考价），无法按面额统一排序，采用随机排序保证公平。
5. 券区标题
   1. 左侧「限时活动券」。
   2. 右侧「查看全部」入口。
 6. 一键领取交互
    1. 点击后仅领取可领券列表中的券，已领或不可领的自动跳过。
    2. 全屏遮罩，中央显示「当前正领取优惠券，请稍等」和实时进度。
    3. 调用批量领券接口，一次提交可领券 ID，成功失败分别统计。
    4. 全部领取完成后遮罩消失。
    5. 弹出结果弹窗：
       1. 主文案统一为「已成功领取社区优惠」，不区分全部成功或部分失败。
       2. 弹窗内展示指引区（预设文字）：
          1. 有效期提示：优惠券在活动时间内有效，过期作废。
          2. 使用方式：进入卡包点击优惠券，到店出示核销码即可使用。
          3. 卡包入口：可前往云芳邻小程序—我的卡包查看，或点击右下角「我的券」浮标进入。
       3. 弹窗仅保留「好的」关闭按钮。
    6. 弹窗点击「好的」关闭，关闭后继续走订阅判断逻辑（未开启订阅则弹出订阅弹窗）。
    7. 领取完成后刷新可领券列表，如无可领券则按钮变为置灰「已领取」。
    8. 执行期间按钮不可重复点击。
7. 按钮状态速查

| 场景 | 判断条件 | 按钮文案 | 按钮状态 |
| --- | --- | --- | --- |
| 有券可领 | 可领券数量 > 0 | 一键领取 | 蓝色可点击 |
| 全部已领 | 可领券数量 == 0 | 已领取 | 灰色不可点击 |
| 活动已结束 | 当前时间超出活动时间 | 活动已结束 | 灰色不可点击，下方展示领券中心引导 |
| 空状态 | 该社区有效活动券为空 | 不展示按钮 | — |
8. 空状态
   1. 无券时展示「当前社区暂无活动优惠券」。

###### 商家列表区 · 商家列表

1. 结构
   1. 两列卡片网格。
   2. 每卡上部为门店头图（彩色背景占位），下部为信息区。
2. 卡片内容
   1. 商家名称。
   2. 距您 xxm（仅已注册且已授权定位的用户显示）。
   3. 无距离时（新用户、未授权定位或无距离数据）展示商家简介替代。
   4. 点击进入商家详情页。
3. 商家取值规则
   1. 取活动配置「参与活动商家清单」中、所属社区为当前社区的商家。
   2. 切换社区后按新社区重新展示对应商家。
4. 加载方式
   1. 商家列表支持向下滑动无限加载（分页加载），不限于固定数量。
   2. 首次进入加载首屏商家，滚动触底时自动加载下一页，加载中展示加载提示。
5. 排序规则
   1. 从当前社区的参与商家中随机乱序排列。
   2. 每次进入页面或切换社区时重新随机，不固定排序。
6. 商家区标题
   1. 左侧「逛逛社区好店」。
   2. 右侧「查看全部」入口。
7. 空状态
   1. 无商家时展示「当前社区暂无参与活动的商家」。

###### 我的券浮标 · 卡包入口

1. 位置
   1. 页面右下角悬浮按钮，文案「券 · 我的」。
2. 已注册用户
   1. 点击跳转「我的卡包」页，查看已领取的优惠券。
3. 未注册用户
   1. 点击弹出注册弹窗，引导注册后进入卡包。
4. 隐藏条件
   1. 空状态、活动结束状态下隐藏浮标。

###### 注册弹窗 · 新用户注册

1. 触发条件
   1. 用户无手机号时，点击「一键领取」或「我的券」浮标弹出注册弹窗。
   2. 用户已有手机号时不弹注册弹窗，直接进入领取流程。
2. 弹窗内容
   1. 顶部标题：「领取优惠券」。
   2. 中部说明：「授权注册即可一键领取【当前浏览社区】活动优惠！」，跟随页面社区显示。
   3. 绑定社区卡片：「绑定社区：XX」+ 右侧「更换绑定社区」按钮，仅无社区的全新用户展示。
3. 两种用户场景
   1. 无手机号 + 无社区（全新用户）：展示绑定社区卡片，支持更换绑定社区。
   2. 无手机号 + 已有社区（老用户补手机号）：不展示绑定社区卡片及更换绑定社区交互。
4. 更换绑定社区（仅全新用户）
   1. 点击「更换绑定社区」弹出社区选择面板，选完后关闭面板回到注册弹窗。
   2. 更换的是注册绑定社区，不影响当前活动页的社区。
   3. 更换后绑定社区卡片中的社区名更新为所选社区。
   4. 不更换则默认绑定当前浏览的社区。
   5. 更换后卡片下方显示提示：「注册后将归属 YY 社区，该社区活动与通知将推送给您」；未更换不显示。
   6. 注册后支持在个人中心修改归属社区，此处为轻量告知，不做二次确认。
5. 注册结果
   1. 全新用户：以所选社区（默认当前浏览社区）完成注册。
   2. 已有社区用户：授权获取手机号后保留原有社区信息，不变更。
   3. 授权成功后自动继续领取流程，不要求再次点击。
6. 弹窗按钮
   1. 「暂不领取」：关闭弹层，返回浏览状态。
   2. 「注册并领取」：按对应场景完成注册，自动返回活动页刷新，不跳离当前社区页面。
7. 异常处理
   1. 授权失败提示「请授权手机号以继续」，可重试。

###### 分享 · 分享活动页

1. 位置
   1. 社区选择器右侧，分享图标按钮。
   2. 无活动内容的社区不展示分享按钮。
2. 交互
   1. 点击分享按钮后，底部滑出分享面板。
   2. 面板包含两个并排选项：「小程序转发」「海报转发」+「取消」。
   3. 小程序转发：调起微信转发弹窗，可转发给好友或群聊。分享卡片使用固定活动标题和活动宣传图，不使用页面截图；分享链接包含当前社区，他人通过分享进入时自动打开对应社区的活动页。
   4. 海报转发：调起微信图片转发，转发当前社区对应的活动海报图片。
3. 分享卡片规格
   1. 分享标题：「社区清凉福利节」（固定，不带日期）。
   2. 分享图比例 5:4（建议 500×400px），大小小于 200KB，图片由运营提供，随活动配置维护。
4. 海报规格
   1. 每个社区一张成品海报（含小程序码），运营制作后按社区挂载。
   2. 前端按当前社区读取对应海报，海报 URL 配置在活动配置中。
   3. 海报带来的回流：用户扫描海报上的小程序码进入，来源记为扫码。
5. 无活动社区处理
   1. 当前社区无活动内容时隐藏分享按钮。

###### 订阅消息 · 活动通知授权

1. 触发时机
   1. 一键领取完成后，结果弹窗关闭时，先判断用户订阅消息推送开关状态。
   2. 订阅开关已打开 → 不弹出订阅弹窗，直接结束流程。
   3. 订阅开关未打开（含首次用户、以及曾关闭过推送的用户）→ 弹出订阅引导弹窗。
   4. 订阅开关状态以平台内部「消息订阅」面板记录为准（后端存储），非微信授权状态。
2. 弹窗内容
   1. 标题：「开启活动通知」。
   2. 描述：「开启后，您将收到优惠券到期提醒、社区活动通知等消息」。
   3. 按钮：「暂不开启」/「允许」。
3. 与领取关系
   1. 订阅弹窗在领取完成后独立弹出，不影响领取流程。
   2. 用户选择「允许」或「暂不开启」均关闭弹窗，不阻塞后续操作。
4. 完整链路
   1. 未注册用户：点击一键领取 → 注册弹窗 → 点击「注册并领取」 → 领取流程 → 结果弹窗 → 判断订阅开关（未开则弹订阅窗）。
   2. 已注册用户（订阅开关已开）：点击一键领取 → 领取流程 → 结果弹窗 → 结束。
   3. 已注册用户（订阅开关未开）：点击一键领取 → 领取流程 → 结果弹窗 → 订阅弹窗。

###### 企微群入口 · 加入社区福利群

1. 位置
   1. 页面底部贴底常驻横幅，全宽展示。
   2. 一键领取下方保留原有蓝色横幅入口（两处并存）。
2. 文案
   1. 贴底横幅：「加入 XX 社区企微群聊获取福利信息」+ 右侧「关闭」（弱化）+「加入」（强化）按钮。
   2. 原有横幅：标题「加入 XX 社区福利群」，副标题「获取 XX 社区最新活动与优惠」，跟随当前社区名称变化。
3. 联动
   1. 切换社区后，群入口配置同步切换。
   2. 不同社区对应不同企微群入口。
4. 贴底横幅展示规则
   1. 每天首次打开页面时展示一次。
   2. 用户操作（点击关闭或加入）后当天不再显示，次日重新显示。
   3. 使用本地存储按日期记录展示状态。
   4. 不判断用户是否已加入群聊，加群前后均按上述规则展示。
5. 交互

   4. 加群为自愿操作，不作为领券或使用优惠券的前置条件。

   4. 未配置的社区不展示此模块，空状态下不展示此模块。

##### 二、关键漏斗与参考数值

漏斗基于上述事件数据计算，每步可得到对应转化率。以下参考数值为首期经验值，首场活动结束后按实际数据校准。

| 漏斗 | 事件链路 | 参考数值 |
| --- | --- | --- |
| 领券主漏斗 | 页面进入 → 一键领取点击 → 领取成功 | 领取点击率 > 30%；成功率 > 95% |
| 注册漏斗 | 未注册用户触发领券或我的券 → 确认注册 → 注册成功 | 注册确认率 > 50%；注册成功率 > 95% |
| 订阅漏斗 | 领取完成 → 允许授权 | 订阅授权率 > 40% |
| 商家漏斗 | 单卡曝光 → 卡片点击 | 卡片点击率 > 5% |
| 传播漏斗 | 分享按钮点击 → 分享回流进入 | 回流率 > 1（一次分享带回超过一人） |

计算口径说明：

- 领取点击率 = coupon_claim_start_click / activity_page_enter
- 注册确认率 = register_dialog_confirm_click /（coupon_claim_start_click + fab_my_coupon_click，均为未注册用户）
- 注册成功率 = register_success / register_dialog_confirm_click
- 订阅授权率 = subscribe_dialog_allow_click / coupon_claim_result
- 卡片点击率 = shop_card_click / shop_card_show
- 回流率 = activity_page_enter（source=share）/ share_button_click

### 数据获取

| 数据 | 来源 | 过滤逻辑 |
| --- | --- | --- |
| 社区列表 | 全区组织树接口 | — |
| 商家列表 | 现有商家列表接口 | 取活动配置「参与活动商家清单」，按当前社区筛选，支持分页加载 |
| 活动券列表 | 现有领券中心券列表接口 | 前端按社区 + 券名称关键词双重过滤，再剔除非免费、不符新客资格、达限领上限的券 |
| 用户已领券状态 | 现有用户已领券查询 | 判断每张券是否已领取；历史领券记录用于核对每人限领上限 |

待确认：券列表接口需返回消耗积分、适用人群、每人限领字段（默认具备）；「新客资格」判断已有现成接口，但接口具体逻辑待研发核对（是否直接返回过滤后结果，或需前端结合核销记录判断）。

### 一键领取

- 复用现有批量领券接口，一次提交可领券 ID 列表
- 成功/失败分别统计用于埋点，弹窗表现统一（「已成功领取社区优惠」+ 指引区）
- 领取期间按钮禁用防重复点击

### 活动时间

- 前端硬编码活动起止时间，非活动期内按钮置灰「活动已结束」
- 活动卡片和各区域保持正常展示，不叠加遮罩
- 券本身不受影响，用户仍可从领券中心正常领取

### 活动配置

活动页所有需前端协助维护的配置项见 `功能一 · 活动配置`，当前前端硬编码，不排除评审后改为后端下发。
