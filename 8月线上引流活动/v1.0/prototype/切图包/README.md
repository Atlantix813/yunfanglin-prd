# 社区清凉福利节透明 PNG 组件包 V2

这套素材按“装饰图层 + HTML 动态内容”拆分。生产开发只使用 `01_主题装饰` 至 `04_交互组件`。

## 使用原则

- PNG 只承载活动装饰、卡片外框和按钮外壳。
- 社区名称、活动标题、券面额、使用门槛、商家名称、商家图片、距离、评分等内容由接口返回后用 HTML 渲染。
- 商家卡片顶部大图区域已经抠空，商家图片放在卡片 PNG 下方。
- 版头中央区域已经抠空，活动标题与活动时间使用 HTML 叠加。
- 保持素材原始宽高比，禁止强行拉伸。
- 推荐图层顺序：动态图片 `z-index: 0`，PNG 外壳 `z-index: 1`，动态文字和交互控件 `z-index: 2`。

## 文件说明

### 01_主题装饰

- `hero_夏日版头透明框.png`：活动版头装饰，中央为透明内容区。
- `bottom_海浪冰块装饰.png`：页面底部或区块分隔装饰。
- `title_优惠券栏目空白飘带.png`：优惠券区标题外壳。
- `title_社区商家栏目空白飘带.png`：商家区标题外壳。

### 02_优惠券组件

- `coupon_粉色空壳.png`
- `coupon_橙色空壳.png`
- `coupon_蓝色空壳.png`

券面额、门槛、有效期、商家名和领取状态均由 HTML 填充。底部金色区域可承载“领取”“已领取”“去使用”等状态文字。

### 03_商家组件

- `merchant_card_透明图片孔位空壳.png`：顶部图片孔位透明，底部信息区留白。
- `merchant_coupon_badge_空壳.png`：叠加在商家卡片右侧的券标签外壳。

### 04_交互组件

- `community_selector_社区选择空壳.png`：页面顶部社区选择器。
- `button_一键领取空壳.png`：一键领取按钮外壳。
- `button_我的券悬浮图标.png`：悬浮入口外壳。

## 推荐显示尺寸

以下为 390px 宽移动端的 CSS 显示宽度，实际可按容器等比缩放：

| 组件 | 建议宽度 |
| --- | ---: |
| 社区选择器 | 358px |
| 活动版头 | 390px |
| 栏目飘带 | 230-270px |
| 单张优惠券 | 108-116px |
| 一键领取按钮 | 330-350px |
| 单张商家卡片 | 174-182px |
| 我的券悬浮按钮 | 56-64px |

完整拼装方式见 `05_开发说明/demo_开发拼装示例.html`，字段清单见 `05_开发说明/assets-manifest.json`。

`00_色键源图` 是透明化处理的中间文件，不参与开发使用，也未收入交付压缩包。
